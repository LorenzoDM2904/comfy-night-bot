# Your components

Components go here: one ComfyUI workflow per folder, with its manifest
(`components/<id>/manifest.json` + `workflow.json`). The repository
contains none: you create them, with the help of an AI if you like,
following [COMPONENTS.md](../COMPONENTS.md).

The contents of this folder stay out of git. To keep them elsewhere
(for example in a private repository of your own) set `COMPONENTS_DIR`
in the `.env`.
